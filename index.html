READ THE RESULT CORRECTLY

Sources & methodology

CONFIRMED

Observed on one console.

Firmware physically verified on the recorded unit or documented by direct original evidence. Initial records preserve Modi’s supplied verification claims; proof has not been independently reviewed here.

ESTIMATED

A reference, not a promise.

Inferred from a matching prefix, batch or sourced production rule. One confirmed console never confirms another console, even with the same model or prefix.

UNKNOWN

Not enough evidence.

No supported match, conflicting box details or no verified firmware. We leave firmware unknown instead of inventing a value.

How matching works & source credits

The longest applicable serial prefix wins. Optional model and production details can narrow a match or flag a conflict. Dates are observations from box labels, not a universal serial-date formula. Community rules always remain estimates and include attribution.

Exploit support is a dated snapshot of public developer documentation. A supported firmware range is not a guarantee of stability, payload support or a complete jailbreak. Estimated firmware produces “Possibly compatible”. Firmware outside the curated ranges is “Not currently known to be compatible”; omitted ranges may still have public support.

Factory firmware and first-observed firmware are distinguished in each record. A System Information photo alone does not prove a console was never updated. For the Wolverine entry, 13.20 is the supplied factory / first-observed value.

    No third-party serial dataset is bundled. Only the three supplied Modi records seed prefix matching. Exploit metadata is transcribed with attribution; no exploit code is included.
